# Практична робота: Створення і використання статичних методів

## Опис

Цей проєкт реалізує практичну задачу з використання **статичних методів** у мові Java. Зокрема, реалізовано обчислення **числа долі** за заданою датою народження.

---

## Варіант завдання №23

📌 **Розрахувати число долі за заданою датою народження**

> Число долі — це сума всіх цифр дати народження, зведена до однозначного числа (1–9).
